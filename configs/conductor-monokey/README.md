# Conductor Monokey

Source of truth for [Conductor Monokey](https://plotoftheprototype.com/products/monokey)
keyboard layout configuration.

## Layout File

- `conductor-monokey.json`: Complete layout export (version 2) containing layer bindings, combos, and macros.

## Apply / Re-import

The layout is applied directly via the Conductor Monokey web/desktop configurator interface:

1. Connect the Monokey keyboard or open the Monokey configurator.
2. Select the import option in the configurator.
3. Import or paste the contents of `conductor-monokey.json`.
4. Flash or save the configuration to the device.
